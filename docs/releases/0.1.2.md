# HarborDrive 0.1.2

Windows x64 (x86-64 / Intel / AMD) offline installer. Includes .NET 10, rclone 1.75.2 and the unmodified official WinFsp 2.1.25156 MSI.

- New application, installer and tray icons; tray colors distinguish disconnected, connected, transferring and error states.
- Detect new stable versions through this repository's GitHub Releases. Check at startup or from Settings; startup checks can be disabled.
- Open the release page to download an update, finish transfers and exit the app safely, then run the new installer. Settings and VFS caches are preserved.
- Protect active apps and transfer engines during install/update/uninstall. Retain the shared WinFsp driver and user caches on uninstall.
- MIT-licensed HarborDrive source and artwork; third-party software retains its original licenses and notices.

The installer and HarborDrive are currently unsigned. WinFsp's embedded original MSI retains its vendor signature. x64 execution has been tested through Windows 11 ARM64's x64 emulation; native Intel/AMD hardware and actual AWS accounts require further validation. See docs/validation.md for test evidence and scope.
