# HarborDrive 0.1.3

Fix opening cache and log folders when Windows redirects AppData for the process that launched HarborDrive. The buttons now resolve the folder's physical location before opening Explorer. Previously Explorer could report that an existing cache folder was unavailable because it used a different file-system view.

Folder creation and path-resolution errors are shown in the app. This update changes local folder navigation only; S3 mount, upload, deletion and cache-retention behavior are unchanged.

Close files opened through the mounted drive, choose **모든 연결 해제 후 종료**, then run the x64 installer. Settings and caches are retained.
