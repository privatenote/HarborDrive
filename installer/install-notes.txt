HarborDrive — Windows x64 (x86-64)

Intel / AMD 64비트 Windows용입니다.

이 설치 파일에는 HarborDrive, .NET 런타임, x64 rclone, 공식 WinFsp 설치 파일이 포함되어 있습니다. 설치 시 인터넷 연결이 필요하지 않습니다.

WinFsp가 없거나 오래된 경우 함께 설치합니다. 드라이버 설치와 Program Files 쓰기를 위해 Windows 관리자 승인이 필요합니다. 재시작이 필요한 경우 설치 완료 화면에서 안내하며, 설치 프로그램이 자동으로 PC를 재시작하지 않습니다.

설치·업데이트·제거 전에 HarborDrive에서 '모든 연결 해제 후 종료'를 선택하세요. 설치 프로그램은 실행 중인 앱이나 전송 엔진을 강제로 종료하지 않습니다.

제거할 때 S3 파일과 사용자 설정·인증 정보·미전송 캐시를 삭제하지 않습니다. 다른 프로그램도 사용할 수 있는 WinFsp도 남겨둡니다.

설치가 끝나면 일반 사용자 권한으로 HarborDrive를 실행하고 S3 연결 정보를 입력하세요.
